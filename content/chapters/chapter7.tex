\chapter{总结与展望}

\section{工作总结}

本文围绕“基于云原生与AI辅助的一体化在线编程评测平台设计与实现”这一课题，完成了在线评测平台的需求分析、总体设计以及关键模块实现说明，并形成了面向高校程序设计教学场景的原型系统方案。通过将题库管理、在线提交、容器化判题和 AI 辅助反馈整合到统一平台中，本文验证了“客观评测为主、智能辅助为辅”的一体化设计思路具有较好的可行性。

从现阶段成果看，平台已经具备较完整的核心业务主链路，能够支撑题目读取、模板加载、代码提交、编译运行、测试用例校验、结果展示以及 AI 分析反馈等主要功能。相比单纯的传统在线判题系统，本文方案更加重视环境隔离、运行可控性以及学习支持能力，在工程实现和教学应用层面都具有一定实践价值。

结合当前阶段已经完成的系统实现、构建验证与论文整理结果可以认为，本文预期的核心目标已经基本达成。平台已经完成题库管理、题目内容组织、模板代码加载、在线提交、容器化编译运行、测试用例判定、提交记录展示以及 AI 辅助分析等关键功能模块的设计与实现，并形成了较完整的业务主链路。从工程验证情况看，项目已经通过 \texttt{npm run lint} 与 \texttt{npm run build} 校验，说明当前系统原型在代码组织、依赖管理和生产构建层面具备较好的可运行性与可维护性，能够满足本科毕业设计对“可实现、可演示、可说明”的基本要求。

从实际效果与成果形态看，本文工作的价值主要体现在三个方面。其一，平台以容器化判题为核心，使代码编译与运行过程具备较好的环境隔离性和结果一致性，能够支撑程序设计教学中的客观评测需求；其二，系统采用工作区式界面组织方式，将题面、代码、提交记录、测试信息和 AI 面板整合在统一视图中，提升了用户完成“读题、写码、提交、复盘”全过程的连续性；其三，AI 模块以异步分析方式嵌入平台，在不干扰客观判题结果的前提下，为学生提供复杂度分析、质量评价和改进建议，增强了平台的教学辅助能力。总体而言，本文已经形成了一个具有明确应用场景、较完整实现链路和后续扩展潜力的一体化在线编程评测平台原型，为后续继续完善多语言支持、任务调度优化和扩展教学功能提供了可靠基础。

\section{不足与展望}

尽管本文已经完成平台核心能力的设计与原型实现，但与成熟在线评测平台相比，系统仍存在若干可以继续改进之处。首先，当前实现主要围绕 C 和 C++ 语言展开，后续可进一步扩展更多编程语言与对应运行镜像。其次，当前判题流程属于较轻量的一次一容器执行模式，后续可以引入任务队列、独立判题节点或更细粒度的资源调度机制，以提升系统在高并发场景下的处理能力。

在 AI 辅助方面，当前系统已经能够给出复杂度分析和反馈建议，但在提示工程优化、反馈稳定性控制、教学边界约束和更细粒度的学习路径支持方面仍有进一步研究空间。若后续项目继续迭代，可以考虑增加更完善的反馈分级机制、异常内容过滤以及基于题目知识点的定向提示能力。

对于扩展功能而言，排行榜等轻量增强能力可以在现有提交记录基础上较容易实现，适合作为后续展示型扩展；而竞赛模块由于涉及比赛组织、时间控制、排名规则和权限设计等新领域模型，工程复杂度明显更高，更适合作为下一阶段的独立扩展方向，而不应影响当前毕设主线的聚焦。
