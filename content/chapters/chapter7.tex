\chapter{研究总结与展望}

\section{研究工作总结}

本文围绕高校程序设计教学场景，完成需求分析、总体设计、系统实现与测试验证，形成一套可运行的在线编程评测原型：以自动判题为核心，容器化隔离执行，AI 在客观结论之外提供解释性反馈；工作区、国际化与主题等交互要求已在第三、四章界定，工程路径与界面证据集中在第五、六章。

验证结果表明，核心判题状态（如 \texttt{AC}、\texttt{CE}、\texttt{WA}、\texttt{RE}、\texttt{TLE}、\texttt{MLE}）与主要界面能力均可按用例复现；工程侧通过 \texttt{bun run lint} 与 \texttt{bun run build} 校验。异步判题、实时回传、提交—判题—用例分层及 AI 结果独立落库等机制的技术细节与数据流见第四、五章，定量与截图证据见第六章，本章不再复述。

\section{不足与展望}

在当前阶段，系统仍有一些不足。本文测试重点放在功能可用性与流程正确性上，高并发提交下的时延、资源利用率和成本变化还缺少系统化压测数据\cite{alemu2023serverless,kubernetesdocs}；教学效果方面也还没有完成课程周期级的对照实验，暂时无法量化 AI 反馈对学习成效和教师干预效率的影响\cite{ihantola2011automated,messer2024automated}。此外，AI 模块的教师审阅、提示词版本管理、学术诚信联动，以及平台的规模化部署和长期运维能力，仍需要继续完善\cite{lubin2025llm,raihan2025llmcsed,nist201716800190}。

后续工作将围绕性能压测、教学验证和工程运维三个方向展开：一方面补充批量提交、峰值吞吐和弹性伸缩测试，形成从单机 Docker 到多节点部署的演进路径\cite{kubernetesdocs,agache2020firecracker,nist201716800190}；另一方面引入教师复核和课程级实验，继续评估 AI 反馈的实际教学价值，并完善日志追踪、异常告警和配置审计等运维能力。未来将在现有系统基础上补齐规模化验证与教学实证工作，进一步提升平台的持续应用能力。
