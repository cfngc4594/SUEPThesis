\begin{abstract}

在线编程评测平台已成为高校程序设计课程的重要基础设施，但多数现有系统主要返回 AC、WA、CE 等状态码，反馈粒度较粗，学生通常需要多次提交并结合报错信息反复定位问题。同时，判题链路的执行隔离、系统扩展性和教学反馈的可解释性在工程实现中往往难以兼顾。围绕这些问题，本文面向本科教学场景，设计并实现了一个基于云原生思路与 AI 辅助的一体化在线编程评测平台。

相较传统单体式教学 OJ 更偏向结果返回的实现路径，本文在工程上同时处理执行安全、反馈前移和解释增强三类技术难点。系统采用提交受理、状态流转与容器化执行相结合的判题链路，在受控 Docker 环境中完成编译、运行与用例比对，并通过资源限制与网络隔离降低执行风险。前端工作区引入 Monaco 与 Language Server Protocol，通过对接容器化 Clangd 在提交前提供诊断与补全，缩短错误定位路径。AI 模块在客观判题之后异步运行，基于提交代码与判题摘要生成复杂度、风格和可读性等结构化分析结果，并以评分雷达图和文本建议呈现，使客观判分与解释反馈保持分离。

本文工作的特点主要体现在架构、数据与交互三个层面。架构上，系统把容器化客观评测、LSP 提交前辅助和 AI 提交后解释组织在同一条教学链路中。数据上，系统建立了可追踪的状态模型与结构化分析模型，判题过程、错误类型和反馈结果都可以落库并复盘。交互上，系统通过一体化工作区整合题面、编辑、提交、测试与 AI 交互，减少了教学场景中的操作割裂。系统验证结果表明，平台能够稳定完成 AC、CE、WA、RE、TLE 五类状态判定，AI 反馈在编译错误、逻辑错误、低效实现与可读性问题等场景下与提交情形基本一致。相较以 UOJ 为代表、主要提供状态码判定的传统 OJ，本文系统进一步提供提交前 LSP 诊断与提交后 AI 解释反馈，提升了教学场景下的可解释性与学习支持能力。

\end{abstract}

\begin{abstractEn}

Online programming judges are widely used in undergraduate programming education. However, many existing systems mainly output coarse verdicts such as AC, WA, and CE, which provide limited pedagogical guidance. In addition, practical deployments often face trade-offs between execution isolation, scalable judging flow, and explainable feedback. To address these issues, this thesis designs and implements an integrated online programming evaluation platform that combines cloud-native execution ideas with AI-assisted feedback.

Compared with traditional monolithic teaching OJ systems that focus primarily on final verdict delivery, this work tackles three technical challenges simultaneously: secure execution, pre-submission assistance, and post-submission explanation. First, the judging pipeline combines submission acceptance, explicit state transitions, and containerised execution, where compilation and testcase evaluation are performed in controlled Docker sandboxes with resource limits and disabled network access. Second, the front-end workspace integrates Monaco with the Language Server Protocol and in-container Clangd, enabling diagnostics and completions before submission and reducing trial-and-error cycles. Third, the AI module is triggered asynchronously after objective judging, and generates structured feedback on complexity, style, and readability from submission context and verdict summaries, while keeping scoring and explanation strictly separated.

The main contributions are threefold: (1) a layered collaborative architecture that unifies containerised objective judging, LSP-based pre-submission assistance, and AI-based post-submission explanation; (2) a traceable state model and structured analysis data model that make judging outcomes and feedback persistable and auditable; and (3) an integrated workspace that consolidates problem reading, coding, submission, testcase inspection, and AI interaction in one workflow. Experimental validation shows that the prototype reliably returns expected outcomes for five core verdict types (AC, CE, WA, RE, TLE), and that AI feedback remains consistent with typical scenarios such as compilation failures, wrong answers, inefficient-but-correct solutions, and poor readability code. Compared with traditional OJ systems represented by UOJ, which primarily provide verdict-oriented judging, the proposed platform further integrates pre-submission LSP diagnostics and post-submission AI explanations to improve interpretability and instructional support.

\end{abstractEn}
