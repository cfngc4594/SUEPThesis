\begin{abstract}

传统的在线编程评测平台一般能够实现自动判题，然而在教学场景之中，还是存在一些不足之处，像是反馈信息太过简略、执行环境隔离不够明晰，并且在集中提交场景下扩展性存在局限。鉴于这些问题，本文依据高校程序设计课程的实际需求，设计并达成了一个借助云原生与 AI 辅助的一体化在线编程评测平台。

本文工作的重点不是单纯实现“提交后给出结果”的基础闭环，而是在保证客观判题稳定性的前提下，进一步增强平台的工程可用性与学习支持能力。系统以自动判题为主线，完成了题库管理、题目展示、模板代码加载、在线提交、容器化编译运行、测试用例判定、提交记录展示和 AI 辅助分析等核心功能。

在判题执行层，平台采用受控 Docker 环境运行用户代码，并结合资源限制、网络禁用和状态流转机制，保证运行环境的一致性与安全性。在反馈层，AI 模块则放在客观判题之后异步运行，结合提交代码与判题结果，对时间复杂度、空间复杂度、代码风格、可读性和效率等内容进行分析，生成结构化反馈与改进建议，且不参与最终判题结论的生成，由此确保学习支持能力以可控、可追溯的方式叠加在客观评测主链路之上。

结合系统实现、构建验证和典型测试结果可以看出，本文所实现的平台已经能够较完整地覆盖程序设计练习、实验训练和课程作业中的主要评测流程，同时在传统自动判题基础上补充了一定的解释性反馈能力。对于本科毕业设计而言，该方案较好体现了容器化判题、工程化组织和 AI 学习辅助的综合应用价值。

\end{abstract}

\begin{abstractEn}

Conventional online programming evaluation platforms are generally capable of carrying out automatic judging. Nevertheless, within teaching contexts they still exhibit certain shortcomings, such as overly brief feedback messages, insufficiently clear isolation of execution environments, and limited scalability when submissions are concentrated. In light of these issues, drawing on the actual needs of programming courses in universities, this paper designs and accomplishes an integrated online programming evaluation platform that leverages cloud-native technology together with AI assistance.

The work of this paper is not limited to building a basic submission-and-judging pipeline. Instead, it focuses on improving both engineering reliability and learning support while keeping objective judging as the core of the system. The platform includes problem management, problem presentation, template loading, online submission, containerized compilation and execution, testcase-based judging, submission history display, and AI-assisted analysis. User programs are compiled and executed in controlled Docker environments with resource limits, network isolation, and explicit status transitions, so that the judging process remains consistent and secure. The AI module runs asynchronously after objective judging and analyzes time complexity, space complexity, code style, readability, and efficiency to produce structured feedback and improvement suggestions.

Implementation results, build verification, and representative test cases show that the platform can support the main workflows of programming exercises, laboratory training, and course assignments. For an undergraduate graduation project, the system demonstrates the practical value of combining containerized judging, engineering-oriented platform design, and AI-assisted learning support in a unified solution.

\end{abstractEn}
