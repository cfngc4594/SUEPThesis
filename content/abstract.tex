\begin{abstract}

本文面向本科程序设计教学场景实现了一套一体化在线评测平台。选题出发点来自实际教学痛点：学生往往只能看到最终判题状态，难以判断失败发生在排队、编译还是运行阶段，而平台侧又需要在安全隔离、并发处理与反馈可解释性之间同时做工程取舍。针对这些问题，本文将客观判题作为主链路，把 AI 能力作为独立的教学辅助链路，避免两者相互干扰。

本文在判题主链路上采用提交受理与异步执行解耦方案：提交入口先创建状态为 QD 的记录并投递 Inngest 事件，由后台函数完成容器准备、源码上传、编译、逐用例运行与清理，执行阶段运行在受控 Docker 沙箱内，结合内存约束和网络隔离保障执行边界，状态变化通过 Soketi 通道实时回传前端，减少轮询开销。为提高可追踪性，数据层将判题信息拆分为 Submission、Judge、JudgeRun 三层模型，分别承载提交摘要、判题主状态和逐用例轨迹，实现从受理到终态的可复盘记录。

在教学支持侧，平台将反馈前移与反馈增强同时落地。提交前，前端工作区集成 Monaco 与 Language Server Protocol，通过容器化 Clangd 提供补全、诊断和签名帮助，提交后，AI 模块以异步方式生成复杂度、综合评分、代码风格、可读性、效率与正确性等多维分析结果，并给出可执行的改进建议，且与客观判题结果分离存储，避免解释模块影响裁决确定性。系统支持中英文界面与题面切换，AI 分析文本可随当前语言环境输出中文或英文反馈。验证结果表明，平台可稳定完成 AC、CE、WA、RE、TLE、MLE 等核心状态判定，异步链路与实时状态推送可连续工作，针对 \texttt{fork()} 滥用、超大内存申请和网络外联请求等恶意样例，系统也能在资源限制与网络隔离策略下阻断风险行为。相较以 UOJ 为代表、主要聚焦最终判题结论的传统教学 OJ，本文系统在保持客观判题稳定性的同时，提供了提交前语义诊断、提交中实时状态可视化与提交后多维解释反馈的一体化能力，体现了面向教学过程支持的系统特色与工程创新。

\end{abstract}

\begin{abstractEn}

This paper implements an integrated online evaluation platform for undergraduate programming teaching scenarios. The starting point of the topic selection comes from the actual teaching pain points: students often can only see the final judgment state, and it is difficult to judge whether the failure occurs in the queuing, compiling or running stage; the platform side also needs to make engineering trade-offs between security isolation, concurrent processing and feedback interpretability. In view of these problems, this paper takes objective judgment as the main link and AI ability as an independent teaching auxiliary link to avoid mutual interference.

In this paper, the decoupling scheme of submission acceptance and asynchronous execution is adopted on the main link of judgment: the submission entry first creates a record with the state of QD and delivers the Inngest event, and the background function completes the container preparation, source code upload, compilation, use case-by-case operation and cleaning; the execution phase runs in a controlled Docker sandbox, and the execution boundary is guaranteed by combining memory constraints and network isolation. The state change is transmitted back to the front end in real time through the Soketi channel to reduce the polling overhead. In order to improve the traceability, the data layer divides the judgment information into three layers: Submission, Judge and JudgeRun, which respectively carry the submission summary, the main state of the judgment and the case-by-case trajectory, so as to realize the repeatable disk record from the acceptance to the final state.

On the teaching support side, the platform moves feedback forward and enhances feedback at the same time. Before submission, the front-end workspace integrates Monaco and Language Server Protocol, and provides completion, diagnosis and signature help through containerized Clangd; after submission, the AI module generates multi-dimensional analysis results such as complexity, comprehensive score, code style, readability, efficiency and correctness in an asynchronous manner, and gives executable improvement suggestions. The results are stored separately from the objective judgment results to avoid the influence of the interpretation module on the certainty of the ruling. The system supports Chinese-English interface and topic switching, and AI analysis text can output Chinese or English feedback with the current language environment. The verification results show that the platform can stably complete the core state determination of AC, CE, WA, RE, TLE, MLE, etc., and the asynchronous link and real-time state push can work continuously. For malicious samples such as \texttt{fork()} abuse, oversized memory requests, and network outreach requests, the system can also block risky behaviors under resource constraints and network isolation strategies. Compared with the traditional teaching OJ represented by UOJ, which mainly focuses on the final judgment conclusion, the system in this paper provides the integration ability of semantic diagnosis before submission, real-time state visualization in submission and multi-dimensional interpretation and feedback after submission while maintaining the stability of objective judgment, which reflects the system characteristics and engineering innovation oriented to the support of teaching process.

\end{abstractEn}
