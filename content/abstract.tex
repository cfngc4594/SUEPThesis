\begin{abstract}

针对传统在线编程评测平台在反馈解释能力不足、运行环境隔离性有限、并发场景下扩展能力不强等问题，本文围绕高校程序设计课程教学需求，设计并实现了一个基于云原生与 AI 辅助的一体化在线编程评测平台。平台以自动判题为核心，构建了题库管理、题目内容展示、模板代码加载、代码在线提交、容器化编译运行、测试用例判定、提交记录展示和 AI 辅助分析等功能模块，形成了较完整的业务闭环。系统采用服务化和容器化设计思路，在受控 Docker 环境中完成程序编译与执行，并结合资源限制、网络禁用和状态流转机制，提高评测过程的一致性、安全性与可维护性；在智能辅助方面，平台在客观判题完成后异步调用大语言模型，对提交代码进行时间复杂度、空间复杂度、风格、可读性、效率和正确性等多维度分析，生成结构化评价结果和改进建议。通过项目实现、构建验证和阶段性测试分析可以看出，本文方案能够较好满足程序设计练习、实验训练和课程作业等场景下的评测需求，在客观评测与学习支持相结合方面具有一定工程实践价值和应用推广意义。

\end{abstract}

\begin{abstractEn}

To address the limitations of traditional online programming evaluation platforms, including weak explanatory feedback, insufficient execution isolation, and limited scalability under teaching workloads, this paper designs and implements an integrated online programming evaluation platform based on cloud-native concepts and AI-assisted feedback for university programming education. Centered on automatic judging, the platform integrates problem management, problem presentation, template loading, online code submission, containerized compilation and execution, testcase-based judging, submission history display, and AI-assisted code analysis into a complete workflow. The system adopts service-oriented and containerized design ideas: user programs are compiled and executed in controlled Docker environments, while resource limits, network isolation, and explicit status transitions improve judging consistency, security, and maintainability. After objective judging is completed, a large language model is asynchronously invoked to analyze time complexity, space complexity, code style, readability, efficiency, and correctness, and to generate structured feedback and improvement suggestions. Implementation results, build verification, and phased testing analysis show that the platform can support programming exercises, laboratory training, and course assignments in higher education, and demonstrates practical value in combining objective evaluation with learning support.

\end{abstractEn}
